# Online Videogame Store "ICE": Sales and Ratings EDA: Marketing Shortlist for 2017
Exploratory data analysis of historical video game sales, platform lifecycles, critic vs. user ratings and ESBR classfications through 2016 to identify the best titles for 2017 marketing campaigns.

#Project Overview
The goal of this project is to analyse, contextualize and discern possible patterns that can translate in identifying what drives videogame commercial sucess. In doing so, it will allow us to distill an actionable shortlist of titles for the 2017 marketing campaigns. This is done by the following steps:
- **Platform Lifecycles:** Identifying which gaming stations are declinining/actively growing heading into 2017
- **Ratings and Commercial Impact:** Comparing how user scores and critic scores affect global sales, as well as the role of the ESRB age ratings in that matter.
- **Statistical Hypothesis Testing:** Test if averague user ratings differ significantly across key platforms (e.g., PC vs Xbox One) and genres (e.g., Sports vs Action).
